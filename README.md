# bluem-partners.com

블루엠파트너스(BlueM Partners) 회사 소개 홈페이지입니다.

- 한 페이지짜리 정적 사이트입니다. `index.html` 하나와 `assets/`의 그림 파일로 이루어져 있습니다.
- GitHub Pages로 공개되며, `main` 브랜치에 올라가면 1~2분 뒤 사이트에 반영됩니다.
- 도메인은 `CNAME` 파일에 적힌 `bluem-partners.com`입니다.

## 문구 고치기
`index.html`에서 `<!-- ② 첫 화면 -->`, `<!-- ④ 하는 일 -->`처럼 번호가 붙은 주석을 찾아 그 아래 글자만 바꾸면 됩니다.

## 소개 영상 넣기
`<!-- ③ 소개 영상 -->` 아래 `hidden`을 지우고, `VIDEO_ID`를 유튜브 영상 ID로 바꿉니다.
