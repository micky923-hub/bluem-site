일하는 방식

  • 미리보기로 함께 확인

    작업할 때마다 검수용 주소가 생겨 휴대폰으로 바로 보고 의견을 주실 수 있습니다.

  • 언어·기기별 화면 검사

    모든 언어와 휴대폰·PC 화면을 찍어 글자 넘침과 깨짐을 확인합니다.

  • 배포 전 자동 검사

    비밀 정보, 깨진 링크, 필수 정보를 검사해 통과해야 사이트에 반영합니다.

  • 운영 비용까지 고려

    사이트 성격에 맞춰 호스팅과 운영 방식을 제안해 불필요한 비용을 줄입니다.

진행 과정

  1. 문의만들고 싶은 서비스, 참고 사이트, 원하는 일정
  2. 요구사항 정리페이지·언어·기능, 도메인과 자료 준비 확인
  3. 견적·제안범위·일정·금액 제안
  4. 계약범위, 검수 기간, 수정 횟수 확정
  5. 기획·디자인화면 구성과 디자인 시안
  6. 개발·검수검수용 주소에서 확인하며 수정
  7. 오픈도메인 연결, 검색엔진 등록 준비
  8. 운영·유지보수오픈 후 수정과 점검

비용은 범위·페이지 수·기능에 따라 달라 상담 후 견적으로 안내드립니다.
