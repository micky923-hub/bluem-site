AI 팀과 사람이 함께 만듭니다

블루엠파트너스는 역할별 AI 직원이 초안과 검사를 맡고, 대표가 최종 결정과 고객 소통을 맡습니다. 모든 팀은 만드는 AI와 검수하는 AI를 나눠 서로의 일을 다시 확인합니다.

대표 (사람)최종 결정 · 고객 소통 · 계약
  • STRATEGY전략기획
    전략실장서비스 기획자

    사업 방향을 정리하고, 무엇을 어떤 순서로 만들지 기능 명세를 씁니다.

  • DESIGN디자인
    디자이너→수석 디자이너 검수

    화면 흐름과 시안을 만들고, 브랜드 기준으로 다시 검수합니다.

  • DEVELOPMENT개발
    기술 리드개발자→검토자운영 담당

    설계와 개발을 나누고, 만든 사람이 아닌 검토자가 코드를 확인한 뒤 배포합니다.

  • SALES영업
    영업 담당→영업팀장 검수

    제안서·견적서 초안의 범위·일정·약속을 팀장이 다시 확인합니다.

  • MARKETING마케팅
    마케팅 담당→마케팅팀장 검수

    홍보 글과 리포트를 과장 표현·숫자 근거 기준으로 검수합니다.

  • CONTENT콘텐츠
    콘텐츠 PD→마케팅팀장 검수

    자체 영상 채널의 소재·대본·자막 초안을 만들고, 저작권·플랫폼 정책 기준으로 다시 확인합니다.

  • OPERATIONS경영지원·정리
    경영지원 담당→경영지원팀장 확인정리 담당

    정산 서류를 계약서와 대조하고, 매달 문서와 파일을 정리합니다.

AI 직원사람(대표)

진하게 표시한 역할이 다른 AI가 만든 결과를 검수합니다.

  • 결정과 발송은 사람이 합니다. AI는 초안과 검사까지만 맡고, 견적 발송·계약·오픈 승인은 대표가 직접 합니다.
  • 모든 프로젝트가 같은 작업 규칙을 씁니다. 한 프로젝트에서 찾은 문제는 공통 규칙과 검사에 반영해 다음 프로젝트에서 반복하지 않습니다.

일하는 방식

  • 미리보기로 함께 확인

    작업할 때마다 검수용 주소가 생겨 휴대폰으로 바로 보고 의견을 주실 수 있습니다.

  • 언어·기기별 화면 검사

    모든 언어와 휴대폰·PC 화면을 찍어 글자 넘침과 깨짐을 확인합니다.

  • 배포 전 자동 검사

    비밀 정보, 깨진 링크, 필수 정보를 검사해 통과해야 사이트에 반영합니다.

  • 운영 비용까지 고려

    사이트 성격에 맞춰 호스팅과 운영 방식을 제안해 불필요한 비용을 줄입니다.

진행 과정

  1. 문의만들고 싶은 서비스, 참고 사이트, 원하는 일정
  2. 요구사항 정리페이지·언어·기능, 도메인과 자료 준비 확인
  3. 견적·제안범위·일정·금액 제안
  4. 계약범위, 검수 기간, 수정 횟수 확정
  5. 기획·디자인화면 구성과 디자인 시안
  6. 개발·검수검수용 주소에서 확인하며 수정
  7. 오픈도메인 연결, 검색엔진 등록 준비
  8. 운영·유지보수오픈 후 수정과 점검

비용은 범위·페이지 수·기능에 따라 달라 상담 후 견적으로 안내드립니다.

자주 묻는 질문

기간은 얼마나 걸리나요?

페이지 수, 언어 수, 기능에 따라 달라집니다. 요구사항을 정리한 뒤 단계별 일정을 함께 제안드립니다.

수정은 몇 번까지 할 수 있나요?

계약할 때 수정 횟수와 검수 기간을 정해 계약서에 숫자로 적습니다. 검수용 주소에서 보시면서 의견을 주시면 됩니다.

오픈한 뒤 관리도 해 주나요?

네. 내용 수정, 페이지 추가, 정기 점검 같은 운영·유지보수를 따로 맡을 수 있습니다.

도메인과 호스팅은 어떻게 하나요?

가지고 계신 도메인을 연결하거나 새로 준비하는 방법을 안내드립니다. 호스팅은 사이트 성격에 맞춰 운영 비용이 적게 드는 방식을 제안합니다.

비용은 얼마인가요?

범위와 기능에 따라 달라 상담 뒤 견적으로 안내드립니다.

만들고 싶은 서비스가 있나요?

만들고 싶은 서비스와 참고 사이트, 원하는 오픈 날짜를 알려 주시면 범위와 일정을 정리해 제안드립니다.
